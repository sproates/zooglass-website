Workbench Scenario Simulator

Workbench is a deterministic timeline simulator. It controls time and event ordering so the same scenario produces the same results in the same runtime environment. That makes failures reproducible and lets you check whether a change fixes them.

ZooGlass’s real runtime makes the decisions. Workbench supplies the events, controls their timing and checks the resulting views against explicit expectations. Replay runs the scenario again and compares the new results with the saved trace.

Evidence from several angles

Individual decisions

Focused tests check strategy rules, corrections, source priority and freshness against expected outcomes.

Repeatable sequences

Timeline scenarios exercise supported combinations of events, faults and restarts. Controlled time makes the difficult cases repeatable.

Real service failures

Service and process crash tests check real connections, durable state, retries and recovery. Browser tests check what users actually see.
