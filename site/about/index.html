ABOUT THE PROJECT

Built by
Ian Sproates.

ZooGlass is an open-source project created by Ian Sproates to explore a practical question: how should applications maintain useful live views when events don’t arrive neatly?

Make the behavior explicit.

Live application views often combine updates from independent systems. Late delivery, duplicates, different entity keys and conflicting sources make “just show the latest” an incomplete rule.

ZooGlass makes those choices configurable and testable. The runtime maintains the view; Workbench supplies controlled scenarios and checks observable results; demo applications make that behavior visible.

The project is an early prototype, written in Java and TypeScript, and released under the MIT licence. Development, designs and verification evidence are available in the public repository.
